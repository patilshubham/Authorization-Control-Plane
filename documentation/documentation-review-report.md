## Purpose & Method

This report records a comprehensive verification and rewrite pass over the documentation suite. Each
substantive claim about routes, contracts, configuration, the data model, the runtime decision
engine, security, observability, and the frontend was re-derived directly from the repository source
rather than trusting the pre-existing prose. Where documentation diverged from code — or omitted
material behaviour — it was corrected or completed, and the change is logged in
[Updates Performed](#updates-performed).

The review treated the existing text as untrusted: accurate statements were kept, but every
high-risk fact (route attributes, type shapes, option binding, entity mappings, status vocabularies,
decision-engine ordering, seeded credentials) was confirmed against source before being retained.

## Source-of-Truth Rule

The repository code is the only source of truth for this report. Statements that could not be
verified from the repository are labelled **"Not identified from the current repository
implementation."** No behavior, endpoint, or configuration was inferred or invented.
